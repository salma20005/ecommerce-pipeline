----------------------------------------------
إعداد جهازك (لو بتفتحي المشروع على جهاز تاني)
----------------------------------------------

1. ثبتي Docker Desktop وفتحتيه
2. git clone https://github.com/salma20005/ecommerce-pipeline.git
3. حملي 2019-Oct.csv من Kaggle وحطية في D:\bigdata\
4. cd ecommerce-pipeline
   ثم docker compose up -d
5. تأكدي إن docker ps يوريك 5 كونتينرات شغالة:
   kafka, producer, namenode, datanode, spark

----------------------------------------------
باقي الشغل (الخطوات المتسلسلة)
----------------------------------------------

الخطوة 4 - Spark Batch ETL (الأولى والأهم):
اكتب سكربت Python في فولدر spark/jobs/ ينفذ:
- قراءة CSV من /data/2019-Oct.csv
- التنظيف: حذف nulls و duplicates و تحويل event_time لـ timestamp
- هندسة features: ساعة و يوم الأسبوع و split لـ category_code
- تجميع على مستوى الـ session:
  عدد view/cart/purchase و مدة السيشن و إجمالي price
- تجهيز dataset تدريب ML (label = هل اشترى؟)
- كتابة النتيجة Parquet في HDFS:
  /processed و /curated

طريقة التشغيل:
docker exec spark /opt/spark/bin/spark-submit --master "local[2]" /opt/spark-jobs/job.py

الخطوة 5 - Spark Structured Streaming:
- يقرأ من Kafka topic user-events
- window 5 دقائق: counts + conversion rate
- anomaly detection بسيطة (threshold)
- يكتب النتيجة لـ ClickHouse (أو Kafka topic تاني event-metrics)

الخطوة 6 - ClickHouse:
- يشتغل كونتينر ClickHouse جديد تضيفيه على docker-compose.yml
- يعمل جداول: metrics و alerts و predictions

الخطوة 7 - MLlib:
- Logistic Regression + Random Forest + GBT على الـ curated data
- Evaluation: AUC-ROC و F1
- split بالوقت عشان مفيش data leakage
- أحسن موديل يتحفظ في HDFS /models

الخطوة 8 - FastAPI:
- endpoint POST /predict ياخد features ويرجع احتمالية الشراء

الخطوة 9 - Airflow (لو خلص وقت):
- DAG: Validate -> CSV to Parquet -> HDFS -> Spark ETL -> Validate -> ClickHouse

الخطوة 10 - Power BI (على جهاز Windows مش Docker):
- يتصل بـ ClickHouse
- 5 داشبورد:
  Business Overview / Product & Brand / Customer Behavior /
  Predictive Analytics / Streaming Monitor

----------------------------------------------
نصائح مهمة
----------------------------------------------

- RAM: اللاب 20 جيجا
  متديش Spark أكتر من 6-7 جيجا
  ومتشغليش كل الكونتينرات الكبار مع بعض

- الـ producer بياخد 8-10 ساعات يخلص الـ 42M event
  عادي سيبه شغال

- كل تعديل تعمله: git commit ثم git push
  عشان التيم كلها تفضل متطابقة
